# ENCY Extension Store — прототип

Кликабельный веб-прототип страницы магазина расширений ENCY. Чистая статика без
зависимостей, построен по **ENCY Core** (скилл `ency-core-design`) — тем же способом,
что и Clouds/Setup Sheet v2.

- Локальный сервер: `node server.mjs` → `http://localhost:4321/`
- `styles.css` — токены ENCY Core + общие компоненты (перенесённая база из v2).
- `store.css` — только специфичное для страницы магазина.
- `store.js` — данные (18 расширений) + интерактив.
- Тёмная/светлая тема — переключается в меню аккаунта (токен-флип, как в v2).

## Что живое

- Поиск, категории-чипы (счётчики деривятся из данных), фильтры Price/Tags/Publisher.
- Сортировка (Popular / Recently updated / Name), грид ↔ список.
- Избранное (звёзды, счётчик Favorites), страница расширения (клик по карточке),
  Install/Installed (живой счётчик установок), сворачивание панели фильтров.
- Заглушки с тостом: Publish, Moderation, Account settings, Log out.
- Новый юзер — `index.html?new` или «Switch to a new user» в меню аккаунта: пустые разделы,
  Publish за замком, регистрация разработчика (тип → профиль → данные → компания → условия),
  загрузка .nupkg с декларацией Schedule A, «on moderation» в My published, выплаты в Earnings.
  Шаги сохраняются в localStorage; «start this account over» внизу Developer сбрасывает.
- Лайки: иконка-счётчик рядом со скачиваниями в карточке/строке/окне деталей, живой toggle.
- Анкета разработчика: шаги вертикальным рейлом слева в одной панели с формой (хейрлайн между
  ними), пройденные шаги кликабельны назад; обязательные поля подсвечиваются по Next и гаснут
  при вводе (общая таблица требований `devReq`); Name/Email — одинаковые инпуты («✓ confirmed»
  внутри поля почты); телефон распознаёт вставку с кодом (+49…/0049…, `adoptDialPrefix`);
  документы на Terms — две смысловые колонки; визард ужат до 760px, группы разделены воздухом.
- Нативные селекты тёмные: `color-scheme` в styles.css + цвета `option`.

## Правила (те же, что в v2)

Плотность CAM-UI: контролы 24px, строки 26–28px, шрифт 11–12px, радиусы 4/8/12,
отступы кратны 4 (тонкая подстройка — 2), без капслока. Иконки расширений — плоские
глифы на тонированных плашках (артворк, как превью деталей в Clouds), палитра — яркие
цвета коллекций.
